# 🌍 Global Retail Sales Dashboard | Power BI

An interactive **Power BI dashboard** built using the **Global Superstore Dataset** to analyze sales, profit, customers, products, regions, returns, shipping, and overall retail performance.

---

## 📌 Project Overview

The **Global Retail Sales Dashboard** is a Business Intelligence project developed using **Power BI** and the **Global Superstore Dataset**.

The project transforms raw retail data into an interactive dashboard that helps analyze:

- Sales performance
- Profitability
- Regional performance
- Product performance
- Customer segments
- Shipping modes
- Discounts
- Returns
- Sales trends
- Top-performing products

---

## 🎯 Business Objective

The main objective of this project is to analyze global retail sales data and provide meaningful business insights through an interactive Power BI dashboard.

The dashboard helps answer questions such as:

- What are the total sales and total profit?
- Which regions generate higher sales?
- Which regions generate higher profit?
- Which product categories perform well?
- Which products generate the highest sales?
- How do sales change over time?
- How do different customer segments contribute to sales?
- How do discounts relate to sales?
- What is the return rate?
- How does shipping mode vary across orders?
- How does performance vary across regions?

---

## 🗂️ Dataset

The project uses the **Global Superstore Dataset** in Excel format.

The dataset contains three tables:

- **Orders** – Main sales transaction data
- **Returns** – Information about returned orders
- **People** – Sales representative and regional information

## 🔄 Project Workflow

### 1️⃣ Data Import

The Global Superstore Excel dataset was imported into Power BI.

The following tables were used:

- Orders
- Returns
- People

### 2️⃣ Data Cleaning & Transformation

**Power Query** was used to prepare the data for analysis.

The data preparation process included:

- Checking data types
- Formatting date fields
- Handling missing values
- Cleaning data
- Transforming required fields
- Preparing tables for analysis

### 3️⃣ Data Modeling

The tables were structured in Power BI to support analysis across sales, returns, regions, and people.

The **Orders** table contains the main retail transaction information.

The **Returns** table provides returned-order information.

The **People** table provides regional and sales representative information.

### 4️⃣ DAX Measures

Created DAX measures for important business KPIs such as:

- Total Sales
- Total Profit
- Profit Margin
- Return Rate
- Total Quantity
- Average Shipping Cost
- Top 10 Product Sales

### 5️⃣ Dashboard Development

Created an interactive dashboard using:

- KPI Cards
- Bar Charts
- Column Charts
- Line Charts
- Tables
- Slicers
- Conditional Formatting
